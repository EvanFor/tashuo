# TA说

TA说是一个以真人表达、内容交流和观点碰撞为核心的社区产品。用户以稳定公开身份参与日常交流，仅在明确允许匿名的指定主题中使用受保护的表达身份。

## 当前开发范围

当前阶段只开发前端，暂不接入后端、数据库或真实认证服务。

- 技术栈：Vue 3、Vite、TypeScript。
- `main`：稳定版本。
- `dev`：日常开发分支，当前所有开发变更进入该分支。
- `src/`：前端源码。
- `docs/`：产品需求与前端开发计划。
- 页面交互暂时使用本地模拟数据和前端状态。

## 本地开发

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

构建与类型检查：

```bash
npm run typecheck
npm run build
```

## 当前阶段

当前目标是完成首页、内容列表、帖子详情、发布、评论、搜索和用户主页等前端页面与交互。暂不引入 Prisma、数据库、后端 API 或真实邮箱认证。未来确定后端方案后，再单独规划前后端对接。
